GTA LIVE READER 2.2 — PWA (iPhone + Android + PC / Remote Play)
Озвучка русских субтитров с экрана в реальном времени

ЧТО ДЕЛАЕТ
- Снимает экран ТВ/монитора задней камерой
- Распознаёт русский (и при необходимости английский) текст в выбранной области (Tesseract.js)
- Как только текст стабильно распознан — озвучивает системным голосом
- Без перевода. Только чтение того, что написано на экране

ИЗМЕНЕНИЯ 2.2
- Режим «Экран (PC)» — захват окна PS Remote Play без камеры (getDisplayMedia)
- На ПК: Chrome/Edge → выбрать окно Remote Play → рамка на субтитры
- Для screen-режима автоматически включается быстрый интервал
- Стабильная картинка = чище OCR и меньше задержек, чем с камеры телефона

ИЗМЕНЕНИЯ 2.1
- Скорость под GTA: интервал по умолчанию 1 сек, устойчивость 1
- Детекция изменений кадра — если субтитр не сменился, OCR не гоняется заново
- Меньший размер canvas для OCR (быстрее на телефоне)
- Whitelist символов диалогов (меньше мусора и путаницы)
- Новая реплика прерывает предыдущую озвучку (реплики не копятся)
- Удержание той же фразы ~4,5 сек
- Адаптивное подтверждение: длинные чистые строки — с 1 кадра

ИЗМЕНЕНИЯ 2.0
- Стабилизация OCR: большой текст больше не мигает на каждом кадре
- Подтверждение фразы (1/2/3 совпадения) + умное сравнение (Levenshtein)
- Пока идёт стабилизация — статус «Стабилизация 2/3…», готовая фраза появляется только после подтверждения
- Удержание уже озвученной строки
- При шуме кандидат сбрасывается постепенно
- Работает одинаково стабильно на Android, iPhone и PC

ИЗМЕНЕНИЯ 1.9
- Кнопка «Остановить речь» — мгновенно прерывает озвучку (если распознало мусор)
- Улучшенный фильтр OCR-мусора: отсекает «алылввг влвлсгм» и похожий набор букв
- Корректная замена символов OCR: | → I, типичные путаницы 0/1
- На Android: pause() больше не ломает синтез (там pause = cancel)
- Подсказка по Android: TTS часто идёт через разговорный динамик — это ограничение Chrome, решается наушниками или выбором вывода в шторке
- Мягкий AudioContext unlock при разблокировке голоса

ПК / PS REMOTE PLAY
1. Установи и запусти PS Remote Play, зайди в игру
2. Открой Live Reader в Chrome или Edge (HTTPS / GitHub Pages)
3. «Разблокировать голос» → «Экран (PC)»
4. В системном окне выбери именно окно «PS Remote Play» (не весь экран)
5. Подгони зелёную рамку только на строки субтитров
6. Готово — OCR идёт по стабильному кадру, без тряски камеры

КАК ПОЛЬЗОВАТЬСЯ (телефон)
1. Задеплой на GitHub Pages (или любой HTTPS-хостинг)
2. Добавь на домашний экран (Safari / Chrome)
3. Нажми «Разблокировать голос»
4. «Запустить камеру» → рамка на субтитры
5. При ненужной фразе — сразу жми «Остановить речь»

ANDROID — ЗВУК ЧЕРЕЗ РАЗГОВОРНЫЙ ДИНАМИК
Это ограничение Web Speech API в Chrome на Android (TTS маршрутизируется как «голосовой» поток).
Из веб-PWA принудительно переключить на медиа-динамик нельзя.
Рабочие варианты:
- Bluetooth / проводные наушники
- В шторке уведомлений во время озвучки выбрать вывод «Динамик телефона» / «This phone»
- Громкость «Медиа» / «Уведомления» — поднять во время речи

ТРЕБОВАНИЯ
- HTTPS обязателен для камеры
- Первый запуск скачивает модель OCR
- Приложение должно оставаться на экране
