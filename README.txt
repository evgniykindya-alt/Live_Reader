GTA LIVE READER 1.3 — iPhone PWA
Озвучка русских субтитров с экрана в реальном времени

ЧТО ДЕЛАЕТ
- Снимает экран ТВ/монитора задней камерой iPhone
- Распознаёт русский текст в выбранной области (Tesseract.js, модель rus)
- Как только текст стабильно распознан 2–3 раза подряд — озвучивает его системным русским голосом iOS
- Без перевода. Только чтение того, что написано на экране

ВАЖНЫЕ ИЗМЕНЕНИЯ ОТ ПРЕДЫДУЩИХ ВЕРСИЙ
- Полностью убран перевод и все API перевода
- OCR переключён на русскую модель (rus)
- Озвучка запускается сразу после стабильного распознавания
- Улучшена разблокировка speechSynthesis на iOS (кнопки «Запустить камеру» и «Проверить голос»)
- Сохранение настроек и истории

КАК ПОЛЬЗОВАТЬСЯ
1. Задеплой на GitHub Pages (или любой HTTPS-хостинг)
2. На iPhone: Safari → Поделиться → На экран «Домой»
3. Подключи AirPods и выбери их выводом в Пункте управления
4. Открой приложение с иконки
5. Нажми «Проверить русский голос и AirPods» — должна прозвучать фраза
6. «Запустить камеру» → разреши доступ
7. Поставь телефон на штатив напротив ТВ, накрой зелёной рамкой область русских субтитров
8. В игре включи русские субтитры и по возможности увеличь их размер
9. Дождись 2–3 стабильных распознаваний → текст озвучится

НАСТРОЙКИ
- Интервал проверки (1.8 / 2.2 / 3 сек)
- Скорость голоса
- Устойчивость (2 или 3 совпадения подряд) — меньше ложных срабатываний
- Выбор конкретного русского голоса iOS

ТРЕБОВАНИЯ И ОГРАНИЧЕНИЯ
- HTTPS обязателен для камеры
- Первый запуск скачивает русскую модель OCR (нужен интернет один раз)
- Приложение должно оставаться на экране (iOS приостанавливает фон)
- Качество OCR зависит от освещения, бликов, размера шрифта и точной рамки
- Нативный Live Text / Vision из веб-PWA недоступен — используется Tesseract.js

УСТРАНЕНИЕ ПРОБЛЕМ
- Нет озвучки: обязательно сначала нажми «Проверить голос». Проверь громкость, режим «Без звука», AirPods в Пункте управления.
- Не распознаёт: приблизь телефон, убери блики, увеличь субтитры в игре, точнее рамку.
- Камера не стартует: только HTTPS + Safari + разрешение камеры.
- Приложение «засыпает»: держи на переднем плане; включи «Автоблокировку → Никогда» на время игры.

ДЕПЛОЙ НА GITHUB PAGES
1. Создай репозиторий
2. Загрузи все файлы (index.html, manifest, sw.js, иконки)
3. Settings → Pages → Deploy from branch main → /(root)
4. Открой выданный HTTPS-адрес в Safari на iPhone → Добавить на экран «Домой»
