GTA LIVE TRANSLATOR 1.2 — iPhone PWA

ЧТО ИСПРАВЛЕНО И ДОБАВЛЕНО В 1.2
- Исправлена автоматическая озвучка на iOS: разблокировка speechSynthesis по жесту пользователя (кнопка «Запустить камеру» и «Проверить голос»), периодический resume при паузе синтезатора.
- Исправлены баги setStatus(..., true) — теперь корректный класс error.
- Переключение провайдеров перевода: Авто / Google (неофициальный) / MyMemory / Lingva.
- Режим Авто пробует Google → MyMemory → публичные инстансы Lingva.
- Явное сообщение при исчерпании лимита MyMemory + автоматический fallback.
- Опциональный email для MyMemory (повышает суточный лимит).
- Сохранение настроек и истории в localStorage.
- Screen Wake Lock (где поддерживается), чтобы экран не гас во время сканирования.
- Улучшенный preprocessing OCR (контраст/порог) и whitelist символов.
- Более устойчивое сравнение субтитров и защита от повторных переводов.

ЧТО ВХОДИТ
- Подвижная и ресайзабельная рамка выделения субтитров (сохраняется).
- Задняя камера.
- Tesseract.js OCR (английская модель) на устройстве.
- Стабилизация текста (2 или 3 совпадения) перед переводом.
- Озвучка системным русским голосом iOS.
- Ручной тест перевода, история, статусы.

ВАЖНО
Это камера + OCR переводчик субтитров. Он НЕ слушает звук игры и не переводит диалоги без видимых субтитров.
PWA должно оставаться на переднем плане с включённым экраном. iOS может приостановить камеру/JS при сворачивании или блокировке.
Подключи AirPods до запуска. Браузер не может принудительно выбрать маршрут вывода — звук идёт на текущее устройство iOS.
Первый запуск требует интернет для загрузки Tesseract.js и модели. Каждый новый перевод тоже требует сеть (кроме уже закэшированных частей).
Публичные API перевода нестабильны и имеют лимиты. Для продакшена нужен свой backend и платный/свой провайдер.
Не отправляйте конфиденциальный текст — он уходит на выбранный сервис перевода.
Камера требует HTTPS. Открытие index.html из Файлов ненадёжно.

ПРО NATIVE OCR НА IPHONE
Штатный Live Text / Vision Framework недоступен из веб-страницы/PWA. В Safari нет публичного API для непрерывного OCR с камеры на уровне нативного приложения. Поэтому используется Tesseract.js (клиентский). Более точные решения — нативное iOS-приложение (Vision + AVFoundation) или облачный OCR с ключом.

КАК ЗАДЕПЛОИТЬ НА GITHUB PAGES
1. Создай репозиторий (например gta-live-translator).
2. Загрузи index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png, apple-touch-icon.png.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Дождись HTTPS-адреса.
5. На iPhone открой адрес в Safari → Поделиться → На экран «Домой».
6. Запускай с иконки на домашнем экране (не из превью файла).

ПЕРВЫЙ ЗАПУСК
1. Подключи AirPods и выбери их выводом в Пункте управления.
2. Открой PWA, по возможности поставь «Автоблокировку» на «Никогда».
3. Нажми «Проверить русский голос и AirPods» — должна прозвучать фраза.
4. В «Тест перевода» вставь английскую фразу → «Перевести и озвучить тест».
5. «Запустить камеру» → разреши доступ.
6. Поставь телефон на штатив напротив ТВ, накрой зелёной рамкой субтитры, подгони размер.
7. В GTA включи английские субтитры и по возможности увеличь их размер.
8. Дождись 2–3 совпадений текста → появится перевод и озвучка.
9. Если рамка мимо — останови, поправь, нажми «Проверить область».

УСТРАНЕНИЕ ПРОБЛЕМ
- Камера не стартует: HTTPS, разрешение Safari, другая программа не заняла камеру.
- OCR не грузится: интернет, перезагрузка PWA.
- Нет текста: крупнее субтитры, меньше бликов, точнее рамка.
- Перевод падает: смени провайдер на Google или Lingva; при лимите MyMemory приложение покажет сообщение и попробует другой.
- Нет голоса: сначала кнопка проверки голоса (разблокирует TTS), громкость, не в режиме «Без звука», выбери русский голос в настройках iOS (Универсальный доступ → Произнесённый контент → Голоса).
- Звук не в AirPods: подключи до запуска и выбери в Пункте управления.
- Приложение «засыпает»: держи на экране; Wake Lock помогает, но не на 100%.

ОГРАНИЧЕНИЯ ПУБЛИЧНЫХ API
- Google (неофициальный client=gtx): без ключа, может начать отдавать 429 или CAPTCHA.
- MyMemory: ~5000 символов/день анонимно, больше с email; при исчерпании — явное сообщение.
- Lingva: зависит от публичных инстансов, они часто падают.

Для стабильной работы рекомендуется свой backend + DeepL / Azure / Google Cloud с ключом.
